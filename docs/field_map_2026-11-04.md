# Field map: the fifty physician credentialing fields

Filed 2026-11-04, written 2026-11-05. The fields a health plan or hospital collects to credential a physician, grouped as a credentialing file is. For each one: the standard that asks for it, the primary source, how often that source changes or must be re-read, and where the garden stands on it today.

**Standards are cited at the family level, from working knowledge.** The NCQA and Joint Commission manuals are paid documents and were not re-read for this file. Confirm an element number in the current manual before quoting it to a buyer. CMS-855I sections and the CAQH ProView 120-day attestation come from the public form and CAQH's own pages.

`freshroot/fields.json` is generated from the table below by `docs/build_fields_json.py`. Edit the table, then run the script; `--check` fails when the JSON is out of date.

## Coverage classes

| Class | Meaning |
|---|---|
| covered today | A live, polled source in the garden holds this field, and the FreshRoot API serves it: as a receipt with its three clocks, or as a provider fact from NPPES. |
| public file | A publisher releases it as a file anyone can get. Not loaded yet. The detail names the file. |
| agreement needed | The primary source sells, licenses or restricts it. The detail names the agreement. |
| self-reported | Only the physician can supply it, on the application or attestation. A primary source may confirm it one record at a time, but no bulk file exists. |
| plan-internal | The credentialing organization makes it: decisions, dates, reviews. |

Headline groups, in the `Drives` column:

- **Expired**: a date or status that lapses, so a credential can be out of date while nothing else changed.
- **Sanctioned**: a finding by a board, a payer or a registry that bars or limits practice or billing.
- **Boarded**: what says the physician is board certified, in what, and whether it is current.

## Reading the counts

13 fields are covered today, 8 sit in public files not loaded yet, 13 need an agreement, 14 only the physician can supply, and 2 belong to the plan. The public files are the cheapest next coverage: board actions (F12) are already loaded by the TX, FL and CA board loaders and need only a receipt writer, and the four CMS files (F26, F29, F41, F43) come from the same catalog as the opt-out and PECOS loaders.
