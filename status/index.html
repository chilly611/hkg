Every source, and how old it is.

The credential data layer is only as good as the file it last read. This page shows, for each source, the date on the publisher’s file, when the garden read it, and when it is due again. Nothing here is hidden when it goes stale.

Fresh means the source was read within its publishing cadence. Due means one cadence has passed. Stale means two. Never means no completed run yet. A monthly publisher is read monthly; polling it daily does not make it daily.

Poll late means the garden has not checked the publisher for a new file in over 90 minutes. The poller runs twice an hour on a schedule that can be delayed; until it checks again we cannot say whether the publisher has missed a release, so a late poll is never shown as due or stale.

Rights shows whether the source’s terms permit redistribution and whether it has passed the acceptance test. Rows from a source that is not accepted never ship to a buyer.

Source: v_source_status, computed at read time from ingestion_runs and the poller’s last check of each source. Written by runs and the poller, never by hand.
